# STATUS.md — Learning a Language with AI

Last updated: 2026-10-31

## What was built

**Learning a Language with AI** — a beginner-friendly manual for using AI
as a patient practice partner to learn a language around a real life.
Plain-English, warm, never-condescending style of Asdale Dynamics, LLC
(*The Massive AI Manual*, dylanasdale.github.io).

### Contents

- `docs/` — 10 markdown chapters:
  - Start Here (orientation, chapter map, five-finger summary)
  - Ch. 1 — Fifteen Minutes a Day (daily plan structure, weekly rhythm,
    minimum viable sessions, pointers to the weekly plan cards)
  - Ch. 2 — Your AI Practice Partner (local model via Ollama as Option A,
    free hosted chat, phone/voice, the 4-line session template,
    one-folder library habit)
  - Ch. 3 — Conversation Drills (the correction loop, 3-level difficulty
    dial, six drills: Daily Round, Shopkeeper, Intake, Twenty Questions
    reversed, Story Wreck, Self-Debate)
  - Ch. 4 — Vocabulary in Plain Files (CSV format spec, the box system,
    vocab.py commands, honest grading, AI jobs for card-making and
    context review, backup habits)
  - Ch. 5 — Check the Grammar (rule of two, real-source checks,
    dictionary game, verified-rules log file, disagreement protocol)
  - Ch. 6 — Films, Songs, Labels (three-question rule, 20-minute scene,
    sticky-note lyric, grocery-label immersion, local-model workarounds)
  - Ch. 7 — The Travel Countdown (itinerary inventory, one situation per
    day, dress rehearsal, rescue phrases, post-trip deflation options)
  - Ch. 8 — Quitting Without Guilt (plateau protocol, good quit vs. rot,
    maintenance months, the "seventy percent" reality check)
  - Glossary (plain-English entries for every term used)
- `templates/` — weekly plan cards (Card 1–4 + blank Card 5), the
  phrase-list template with a filled starter example, and a starter
  vocabulary CSV.
- `scripts/vocab.py` — zero-dependency spaced-repetition tool over a
  plain CSV (`word,meaning,due,box,note`): add / due / review / stats,
  Leitner-style boxes (1→2→4→8→16→32→64 days, miss drops to box 1),
  session-capped (`--max`, default 12), case-insensitive dedupe, robust
  against malformed rows and closed stdin.
- `vocab/sample-vocab.csv` — 12-word starter example (Spanish).
- `build.py` — stdlib-only static site generator (docs chapters + the
  three template pages + a templates index + chapter index), shared
  styling, prev/next navigation, internal link/anchor verification.
- `site/` — built static HTML (generated by build.py; not committed).
- `test.py` — 17-test suite (vocab logic incl. grade ladder, dedupe,
  junk rows, CLI behavior; build check; raw copyables match sources).
- `README.md` — overview, run instructions, layout, credits.
- `LICENSE` — MIT, `Copyright (c) 2026 Asdale Dynamics, LLC`.
- `.gitignore` — excludes `site/` and Python cache files.

### Relationship to the sister guide

Complements `study-smarter-ai-guide`: that guide owns the general study
skills (notes→quizzes, explain-it-back, hallucination-spotting,
spaced-review theory). This guide references it (chapters 0, 4, 5, 8)
instead of repeating it, and focuses on language-specific practice:
conversation drills, plain-file vocabulary, grammar verification against
real sources, immersion tricks, travel intensives, and plateau recovery.

## How to run it

```bash
python3 build.py            # build the site into site/
python3 build.py --check    # build + verify structure, links, content
python3 test.py             # full test suite (build check included)

python3 -m http.server 8000 --directory site   # serve; open localhost:8000
# or just open site/index.html in a browser

python3 scripts/vocab.py due     # what's due today (uses starter vocab by default)
python3 scripts/vocab.py review  # an interactive spaced-review session
python3 scripts/vocab.py stats   # boxes at a glance
python3 scripts/vocab.py --file my-vocab.csv add perro dog "note here"
```

Requirements: Python 3.8+ (developed and verified on Python 3.13),
standard library only. Nothing installs; nothing leaves the machine.

## Known gaps

- `vocab.csv` supports one target language per file; multi-language
  means separate files (intentional, explained in ch. 4, but untested
  beyond single-file usage).
- No automated test for the HTML pages' visual rendering (build check
  verifies structure/links/content textually only).
- Recorder/voice integration is described in prose only; no voice-mode
  tooling is shipped (typing + speak-aloud covers the method).
- Markdown renderer covers the subset this guide uses (fences, headings,
  tables, flat lists, quotes, inline styles); nested lists are
  unsupported by design.
- Template dates (starter vocab CSV, template version lines) reference
  build-time dates rather than syncing with repo init date.
